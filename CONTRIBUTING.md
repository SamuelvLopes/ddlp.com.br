# Contribuindo para o DDLP

Obrigado por querer contribuir com o `ddlp.com.br`.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch com uma descrição clara da mudança.
3. Faça alterações pequenas e objetivas.
4. Teste localmente abrindo o `index.html` no navegador e validando os fluxos alterados.
5. Abra um Pull Request explicando:
   - o problema
   - a solução proposta
   - como validar

## Padrões do projeto

- Mantenha o site estático (HTML, CSS e JavaScript puros).
- Preserve o suporte multilíngue (`data-i18n` e traduções no `script.js`).
- Evite mudanças visuais amplas sem contexto no PR.

## Boas práticas

- Não inclua segredos, tokens ou credenciais.
- Prefira mudanças pequenas para facilitar revisão.
- Atualize este guia quando o processo de contribuição mudar.
